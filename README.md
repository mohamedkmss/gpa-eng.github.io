## 🏗️ النمط المعماري الجديد

### 1. **MVVM Pattern** (Model-View-ViewModel)
- **Model (Store.js)**: إدارة البيانات والحالة المركزية
- **View (UI.js)**: عرض البيانات والتعامل مع DOM
- **ViewModel (App.js)**: الربط بين النموذج والواجهة

### 2. **فصل الاهتمامات (Separation of Concerns)**
- كل ملف له مسؤولية واحدة واضحة
- سهولة الصيانة والتطوير
- تقليل التداخلات والأخطاء

### 3. **State Management باستخدام Proxy**
- مراقبة تلقائية للتغييرات
- تحديث الواجهة عند تغير البيانات
- حفظ تلقائي في localStorage

## 📝 الملفات الرئيسية

### `store.js` - إدارة الحالة
```javascript
// إضافة مادة
appStore.addCourse({ name: 'رياضيات', grade: 85, credits: 3 });

// حذف مادة
appStore.removeCourse(courseId);

// الاشتراك في التغييرات
appStore.subscribe((key, newValue) => {
    console.log(`تغير ${key}:`, newValue);
});
```

### `ui.js` - واجهة المستخدم
```javascript
// عرض إشعار
UI.showToast('تم الحفظ بنجاح', 'success');

// تحديث المعدل
UI.updateGPA(3.75);

// التحقق من الإدخال
UI.validateInput(inputElement, { required: true, min: 0, max: 100 });
```

### `api.js` - واجهة البرمجة
```javascript
// حفظ مفتاح API
API.saveApiKey('your-api-key');

// الحصول على توصيات
const recommendations = await API.getRecommendations(courses, gpa);
```
